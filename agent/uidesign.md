Build a production-quality Gym Management web application.

The product should be inspired by the functionality of modern gym
management platforms such as FitBoat, but the UI must be completely
original and should not visually copy FitBoat.

Design philosophy:
- Professional
- Minimal
- Modern
- Practical
- Human-designed
- Easy for non-technical gym staff
- Fast to operate
- Production SaaS appearance

The application must NOT look AI-generated.

Avoid:
- Excessive gradients
- Glassmorphism
- Neon colors
- Excessive rounded cards
- Huge typography
- Excessive animations
- Decorative AI illustrations
- Unnecessary shadows
- Too many colors
- Fake-looking statistics
- Over-designed dashboards

Use:
- White and soft-gray backgrounds
- Charcoal/dark text
- Emerald green as the primary accent
- Subtle borders
- Small shadows
- 8px-12px border radius
- Clean typography
- Lucide icons
- Dense but readable tables
- Practical forms
- Clear status badges
- Realistic Indian gym data
- Proper empty/loading/error states
- Responsive desktop/tablet/mobile layouts

The UI should feel like a real SaaS product used daily by a
gym receptionist, manager and owner.

Prioritize usability and information hierarchy over visual effects.

Every important action should require no more than 2-3 clicks.

Create a consistent design system across the entire application.
